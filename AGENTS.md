# AGENTS.md

## Projet

Ce dépôt contient uniquement le frontend React et Vite de Greenhouse Customer Support.

## Règles

- Utiliser npm.
- Utiliser JavaScript et JSX, sans TypeScript.
- Utiliser exclusivement les ES Modules.
- Utiliser React Hook Form pour les formulaires applicatifs.
- Conserver les communications avec l'API dans `src/services`.
- Ne jamais versionner de secret ou de fichier `.env`.
- Exécuter `npm run build` après une modification susceptible d'affecter la compilation.
- Consulter les fichiers `AGENTS.md` plus proches avant de modifier leur périmètre.
- Ne jamais utiliser le tiret cadratin Unicode dans les contenus du projet.

## Commits

Utiliser le format `type(front): description courte à l'infinitif`.
